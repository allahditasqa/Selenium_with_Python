## Overview
Labels and links, broken link entries, the three form sections, the Shadow DOM widget, footer navigation and the visitors counter.

## Scope and notes
- Broken link cases call the deadlinkcity.com test site directly and need internet access (marked `external`).
- Each form section input is checked for independence from the other two.
