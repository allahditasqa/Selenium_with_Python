# Tables Test Cases

**Automation:** `tests/ui/test_04_tables.py`  |  **Report:** `reports/tables/Tables test <DD-MM-YYYY>_<HH-mm-ss>.html` (all reports: `reports/index.html`)
**Application:** https://testautomationpractice.blogspot.com/  |  **ID prefix:** `TC_TABLE_`  |  **Master CSV:** `docs/test-cases/tables.csv`

## Overview
The practice site has three tables: a static book table, a dynamic table with changing values and a paginated product table with selection checkboxes.

## Scope and notes
- The dynamic table changes its values and column order on every refresh, so cases read cells by header text and never by position.
- The paginated table has four pages with five products each.
